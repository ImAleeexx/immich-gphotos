2. Google Photos

auth_data can only be extracted from an Android device — no daemon can automate this part. The easiest way, no root required:

  1. Install GmsCore and a patched Google Photos on the device, and connect it over ADB.
  2. On your PC, watch the device log for the auth request: 
    adb logcat | grep "auth%2Fphotos.native"
    (Windows: adb logcat | FINDSTR "auth%2Fphotos.native")
  3. If GmsCore already has an account signed in, remove it first, then open the patched Google Photos app and sign in.
  4. A matching log line appears in the terminal. Copy everything from androidId= to the end of that line — that whole string is auth_data.

Rooted device instead? See gpmc's HTTP Toolkit method.
